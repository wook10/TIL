# React-Native란 무엇인가?
React-Native는 페이스북에서 개발한 오픈소스 모바일 앱 프레임워크로, 자바스크립트와 React를 사용해 IOS와 안드로이드 모두에서 작동하는 앱을 만드는 기술이다.

## React와 React-Native의 차이점
React는 웹 브라우저 환경에서 사용자 인터페이스(UI)를 구축하은 라이브러리이다.
React-Native는 모바일 환경에서 네이티브 UI 컴포넌트를 활용해 앱을 만든다.

## 핵심 특징
- 크로스플랫폼 지원: 하나의 코드 베이스로 IOS와 안드로이드 모두 앱 개발 가능하다.
- Hot Reload: 코듸 수정 시 앱 전체를 다시 시작하지 않고 변경된 부분만 빠르게 반영 가능하다.
- 네이티브 UI 사용: 성능과 사용자 경험이 우수한 네이티브 요소로 화면 구현한다.

## 주요 컴포넌트
- View: 레이아웃을 잡을 때 사용하는 기본 컨테이너
- Text: 텍스트 표시
- Image: 이미지 출력
- Button: 버튼 생성
- ScrollView: 스크롤 가능한 화면
- FlatList: 긴 리스트 표시
